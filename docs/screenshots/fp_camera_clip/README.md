# Камера от первого лица не проходит сквозь геометрию

Снимки сделаны в живой игре (Godot MCP). Каждая пара снята в один и тот же момент:
`before_*` — упор камеры выключен (`player.cam_clip_enabled = false`, камера как раньше),
`after_*` — включён.

Большинство кейсов сняты на тестовой площадке, собранной прямо в запущенном полигоне
(стена, внутренний угол, колонна, низкий потолок 1.95 м, плита 1.3 м под присед).
Настоящая дверь квартиры (door.gd) и прыжки по лестнице сняты в подъезде.

| Кейс | Снимки |
|---|---|
| Лицом в стену стоя: прямо / вниз / вверх | `wall_stand_*` |
| Шагом в стену | `wall_walk_*` |
| Бегом в стену с разбега, кадр в момент удара | `wall_run_*` |
| Вприсядку в стену | `wall_crouch_*` |
| Внутренний угол, поворот на 360° (половина круга — взгляд вниз) | `corner_in_*` |
| Внешний угол колонны, поворот на 360° | `corner_out_*` |
| Прыжок под низким потолком | `jump_low_ceiling_*` |
| Присед под плитой, попытка встать | `crouch_slab_*` |
| Удар, замах, сильный удар, бросок, Push, Interact вплотную к стене | `wall_attack`, `wall_aim`, `wall_heavy_attack`, `wall_throw`, `wall_push`, `wall_interact` |
| Сильная тряска вплотную к стене | `wall_shake_*` |
| Настоящая дверь подъезда захлопывается перед лицом | `real_door_*` |
| Прыжки вверх по лестнице подъезда | `stairs_jump_*` |
| Смерть у стены, спиной к стене, спиной в угол | `death_wall_*`, `death_back_to_wall`, `death_corner_back_*` |
| Взгляд вниз вплотную к стене в подъезде (видна грудь, срез шеи — нет) | `after_stairwell_wall_look_down_max` |

## Автоматическая проверка

Каждый физкадр пробник проверял: (1) пересекает ли мир сфера радиусом с полудиагональ
ближней плоскости в позиции камеры; (2) есть ли стена на луче от опорной точки в капсуле до камеры.
Считались только кадры с включённым упором.

| Прогон | Кадров | Сфера ближней плоскости в стене | Луч до камеры перекрыт |
|---|---|---|---|
| Бег вдоль стены с прижатием к ней, 4 прохода, голова к стене и вниз, тряска — **с упором** | 520 | **0** | **0** |
| То же — **без упора** (контроль: тест действительно ловит проблему) | 520 | 68 | 12 |
| Стена стоя/шагом/бегом/вприсядку, углы, потолки, тряска, удары, дверь, смерть, лестница | ~3300 | 0 | 0 |

Стоимость проверки — один `cast_motion` за кадр, в среднем ~5 мкс.
