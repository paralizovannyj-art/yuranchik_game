## Статусы ответа

| Статус | Что значит |
|---|---|
| открыт | ещё не спрашивали |
| из документов — подтвердить | ответ взят из GDD, MVP, ROADMAP, CITY_PLAN или кода; нужно «да» или поправка |
| ответ | решено, есть запись в журнале |
| по умолчанию | принят вариант Claude |
| позже (событие) | отложено до события, например «после механик» |
| исследовать | нужно изучить или посчитать — в [open-questions.md](open-questions.md) |
| пропущен | не про эту игру |

## Как отвечать

- «14 — второй» — записан вариант 2.
- «По умолчанию» или «по умолчанию на всю пачку» — приняты варианты Claude.
- «Не знаю» — Claude даёт 2–3 варианта с плюсами и минусами.
- «Позже — когда будет прототип» — вопрос отложен до события.
- «Исследовать» — вопрос уходит в исследования.
- «Пропусти» — не про эту игру.
- Свой ответ — записывается вашими словами.
