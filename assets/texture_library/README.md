# Библиотека фототекстур

Исходники в высоком разрешении (1K). Godot их **не импортирует** (`.gdignore`):
это склад, из которого делаются PS2-версии в `assets/textures/`.

## Лицензия

Всё в `ambientcg/` — с [ambientCG](https://ambientcg.com), лицензия **CC0 1.0**
(общественное достояние): можно использовать в игре, менять, продавать, без указания автора.

## Что есть

| Набор | Что это | Где используется |
|---|---|---|
| Concrete036 | старый тёмный бетон | фасад панелек |
| Concrete034 | светлый гладкий бетон | торцы, парапеты |
| Concrete012 | старая штукатурка | стены гаражей |
| PaintedPlaster006 | облезлая крашеная штукатурка | тамбуры подъездов |
| Tiles140 | ржавая тёмная плитка | цоколь |
| Snow013 | снег с грязью и следами | земля |
| Snow012 | бурая каша / тропинка | дорожки |
| Road013A | треснутый асфальт | дорога |
| Metal021 | ржавый металл с потёками | фонари, кондиционеры |
| CorrugatedSteel006A / 007A / 008A | профнастил: зелёный, синий, ржавый | ворота гаражей |
| PaintedMetal006 | зелёный крашеный металл | мусорки, забор, турник |
| PaintedMetal013 | ржавый крашеный металл | двери подъездов |
| Bricks105 | кирпич | запас |
| Planks023A | тёмные доски | лавки |
| Bark006 | кора | деревья |

Файлы в каждой папке: `*_Color.jpg` — цвет (главное для PS2-стиля), остальное
(Normal, Roughness, AO, Metalness) — про запас.

## Как добавить новую

1. Скачать набор `*_1K-JPG.zip` с ambientcg.com.
2. Положить картинки в `ambientcg/<Имя>/`.
3. Попросить Claude сделать PS2-версию (скрипт `tools/blender/textures.py`).
