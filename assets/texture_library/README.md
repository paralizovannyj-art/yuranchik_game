# Библиотека фототекстур

Исходники в высоком разрешении (1K). Godot их **не импортирует** (`.gdignore`):
это склад, из которого делаются PS2-версии в `assets/textures/`.

## Лицензия

Всё в `ambientcg/` — с [ambientCG](https://ambientcg.com), всё в `polyhaven/` — с [Poly Haven](https://polyhaven.com);
обе библиотеки — лицензия **CC0 1.0** (общественное достояние): можно использовать в игре, менять, продавать,
без указания автора.

Квартира 47 сделана ещё и из фото автора — настоящей квартиры (`docs/references/apartment/`): прихожая,
коридор, комната, коллаж манги (страницы — чужие сканы манги, автор разрешил: игра для друзей, не для продажи).

## Как добавить новую

1. Скачать набор `*_1K-JPG.zip` с ambientcg.com (или 1k JPG с polyhaven.com).
2. Положить картинки в `ambientcg/<Имя>/` (`polyhaven/<имя>/`).
3. Попросить Claude сделать PS2-версию. Общие функции «фото → PS2-текстура» (выпрямить перспективу, убрать свет,
   бесшовность, склейка кусков, перекраска в тон зоны, грязь) — `tools/blender/photo_tex.py`.
